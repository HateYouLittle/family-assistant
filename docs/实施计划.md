## 红线（每份任务书都带）

- 不 `commit` / 不 `push` / 不重启服务 / 不发通知——提交由 Hermes 做。
- 不动 `data/`（生产库）；测试用临时库。
- 不要用 `git stash`；要临时对比就 `cp` 到 `/tmp`。
- ESM 相对导入必须带 `.js` 后缀；`tsc` 严格模式不放过 `any` 逃逸。
- 业务规则（可见性 V1–V9）**只在 domain 层**，工具层薄壳。
- 遇到分叉自己裁决（任务书 > 实测 > 设计文档 > 偏好），**不许提问**，把决定写进报告。
